# Afterglow updates

New versions of the Afterglow music app for Android.

Afterglow 3.7 and later look here by themselves, show a notification when a new version is ready, and install it for you.

To install by hand, open the [latest release](https://github.com/sufyanyoussef10-beep/afterglow-updates/releases/latest) and download:

- `Afterglow-Android-<version>-arm64.apk` for most phones, or
- `Afterglow-Android-<version>.apk` if the phone says the first one is not compatible.

Each `.sha256` file holds the checksum of its APK. Only the finished app is here.
